# 파이프라인

## 흐름

```
[콘텐츠]  미디어 → 이벤트 그래프 (장면·시간순·근거 span)
[시청 중]  hard block → A.X K1 draft → EXAONE judge → refine → 질문
[시청 후]  회상 발화 → 장면 매칭 → 순서 채점 (Kendall's tau, 오류 유형)
[분석]     원본 오디오 →(STT 무관) 음향 51 / 전사 → 언어 19 → 분류기 + 10축 스코어링
[리포트]   규칙 점수 → 믿:음 근거 설명 → Solar 보호자 리포트 → EXAONE 교차검증
```

프론트 없이 CLI로 동작 (`src/session.py`)
`Responder` 클래스만 교체하면 프론트·STT 연결 가능

## 이벤트 그래프

AI-Hub 방송콘텐츠 Sample 4편 (뉴스·교양·문화·생활)

* mp4 + 라벨링 JSON (타임스탬프 전사 + 하이라이트)
* 하이라이트 1개 = 장면 노드 1개, 시간순 = 정답 순서
* 장면 12개, 근거 transcript span 보존
* user_query 72개 → 질문 평가셋
* 이벤트 그래프 소스 확보 (외부 데이터셋 불필요)

## 타이밍 게이트

hard block(규칙) → draft(A.X K1) → judge(EXAONE) → refine

hard block을 LLM 앞에 둔 이유

* A.X가 팀당 RPS 3 (팀원과 공유) → 규칙으로 먼저 걸러야 API 아끼고 지연도 줄어듦

차단 조건

* 직전 질문 후 90초 미만
* 장면 경계 ±3초 (몰입 구간)
* 세션당 5회 초과
* 사용자 발화 중

실측: 뉴스 1266초에서 84개 평가 시점 중 5회 질문 / 80회 침묵

LLM 실패 시 보수적 침묵

## 회상 응답 매칭

자유 발화 → scene_id 순서

* 1차 키워드 규칙 → 2차 Solar 보정 (규칙이 다 못 잡았을 때만)
* 매칭마다 근거 보존, 확신 없으면 매칭 보류 (min_confidence 0.7)

버그 수정 기록

* 뉴스 장면 3·4가 "미국" 키워드를 공유 → 한 번 언급이 두 장면에 매칭
* 실제 누락을 정상 회상으로 오판 (놓친 기억을 정상 처리)
* → 고유 키워드만 규칙 매칭에 사용
* LLM 매칭도 min_confidence 0.5 → 0.7로 상향

## 순서 회상 채점

score_recall_order(response_events, event_graph)

* Kendall's tau (순서 일치도)
* 오류 유형: omission / reversal / intrusion / cue_dependency
* coverage (회상한 장면 비율)

## 모델 6종

* A.X K1 — 시청 중 질문 생성
* A.X STT — 음성→텍스트. Batch가 화자 분리 지원
* EXAONE — 질문 타이밍 판정 + 교차검증
* Solar — 요약 / 장면 매칭 / 보호자 리포트
* 믿:음 — 탐지 근거 설명 (피처명 44개 우리말 사전 함께 넘김)
* VARCO — 데모 음성 합성

점수는 규칙, 해석은 LLM

* LLM에 채점 안 맡김 → 재현 안 되고, "왜 63점인가"에 답 못 하고, AUC로 검증도 못 함

생성과 검증 모델 분리

* Solar가 쓴 리포트를 Solar가 검증하면 같은 편향 공유 → 검증은 EXAONE

## Rate limit

A.X 팀당 RPS 3, Retry-After 헤더 미제공

* 클라이언트에서 호출 간격 강제 + 429 지수 백오프 (1s → 2s → 4s)
* 컨텍스트 128,000자 한도 → 120,000자에서 자동 절삭
