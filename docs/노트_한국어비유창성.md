# 한국어 비유창성

## 배경

버벅임 축이 5축 중 최약 (0.684)

* 구성이 간투사 정규식, 단어 반복, 휴지 빈도 셋뿐 → 표면만 긁음
* 실제 Kang MCI 발화는 더 풍부
   * "아니, 이제 우리, 저기 뭐야 거기 내, 저기 뭐야 으, 제가 즈, 나, 제, 제가 저기, 거기서 일하는 거 있어요"
   * 단어 찾기("저기 뭐야") / 파편 반복("즈, 나, 제, 제가") / 지시어 남용("저기")

## 1차: 믿:음(LLM) → 실패

마커 6종 탐지 시킴: 조사 오류 / 어미 미완성 / 자기 수정 / 지시어 남용 / 단어 찾기 / 응집성 붕괴

* 짧은 예문(37자)에선 정확. 근거까지 집어냄
* 실제 대화체 전사에선 실패
   * MCI 발화의 명백한 비유창성을 못 찾음
   * HC 발화에서 없는 마커를 만들어냄 (긴 문장을 통째로 "조사 오류"로 인용)
* 청크 3000자 → 329자로 줄이고 프롬프트 조여도 해결 안 됨
* AUC 0.50~0.55

디버깅 기록

* 처음엔 "호출 실패"로 보였음
* 예외를 잡아 빈 결과로 되돌리는 코드 때문에 '실패'와 '마커 없음'이 구분 안 됨
* → 검증기가 데이터 없이 "채택 보류" 판정 내릴 뻔
* 원시 응답 직접 보고 나서 모델은 정상이고 과제 주는 방식이 틀렸다는 걸 확인

## 2차: 규칙 기반 → 성공

* 관찰된 패턴이 규칙적이라 정규식으로 직접 잡음. API 없이 완전 재현
* 어미 미완성 0.736 / 파편 반복 0.726 (MCI가 19배) / 지시어 남용 0.692
* 버벅임 축 0.690 → 0.879
* 전체 분류기 0.833 → 0.897

마커 7개 전부(0.894) < 검증 통과한 3개만(0.897)

## 길이 편향

발화당 정규화 시 간투사가 AUC 0.785로 최강 신호처럼 보임

* 형태소당으로 바꾸니 0.578로 붕괴
* 원인: HC 발화 27.5형태소 vs MCI 15.8형태소 → 길게 말하면 뭐든 많이 나옴
* 인접반복(0.680→0.521), 단어찾기(0.603→0.520)도 동일

살아남은 것 (형태소당)

* 어미 미완성 0.736 / 파편 반복 0.726 / 지시어 남용 0.692

→ 모든 언어 피처를 형태소당으로 통일
