# AI-Rookie 음향 피처

## 왜 STT를 안 거치나

A.X STT가 음성을 텍스트로 → 발화를 매끄럽게 다듬는 문제 발생

* 음성에 있는 더듬거림이 MCI의 증거인데 다듬으면 곤란
* 실측: "제가 즈 , 나 , 제 , 제가" → "제가"
* 어미 미완성 보존율 43.6%, 파편 반복 14.4%만 남음
* 판별력 gold 0.760 → STT 0.527 (거의 무작위)

→ 음향 피처는 STT를 거치지 않고 **원본 파형에서 직접** 추출
→ CLAUDE.md에 '안전망'으로 써둔 설계가 실제로 필요했음이 입증됨

## 시계열 → 51차원

원본 16kHz 시계열 → 900초면 1440만 개 샘플. 그대로 못 씀

**1단계. 프레임으로 쪼갬**

* 25ms씩 자르고 10ms씩 밀면서 각 순간의 음높이·떨림·스펙트럼 계산
* 25ms인 이유 → 성대 1회 진동이 5~10ms. 25ms면 2~3회 들어가서 "이 구간 음높이 170Hz"라고 말할 수 있음
* 더 길면 그 안에서 음높이가 변해버려서 하나로 못 말함
* 10ms씩 미는 이유 → 25ms 재고 25ms 옮기면 경계에서 정보 끊김. 10ms면 15ms씩 겹쳐서 변화를 부드럽게 따라감
* 900초 ÷ 10ms = **화자당 9만 프레임**

**2단계. 통계로 요약**

* 지표마다 9만 개 숫자가 쌓임 → 그대로 못 씀
* 평균·표준편차로 줄임 (예: 음높이 9만 개 → 평균 170.9Hz, 표편 47.0Hz 두 개)
* 하루 체온 1440번 재서 "평균 36.5도, 변동폭 0.3도"로 줄이는 것과 같음

**3단계. 화자당 고정 길이 벡터 = 51차원**

## 51개가 어떻게 나오나

**MFCC 26개** ← 절반이 여기

* MFCC = 스펙트럼을 13차원으로 압축한 음색 지문
* 13차원 각각에 9만 프레임의 평균·표편 → 13 × 2 = 26

**음질 12개**

* 같은 걸 여러 방식으로 잼
* 음높이 4개: f0_mean, f0_std, f0_range, f0_cv(변동계수)
* jitter 3종: local, rap, ppq5 → 짧은 주기 / 중간 주기 떨림을 따로 봄
* shimmer 3종: local, apq3, apq5
* HNR 1개(배음 대비 잡음 = 맑기), CPP 1개(주기성·명료도)
* 3종씩 넣은 이유 → 어느 게 신호인지 미리 모름. 표준 패널 다 넣고 데이터로 고름

**휴지 6개**

* pause_ratio(쉬는 비율), pause_rate(빈도), pause_dur_mean/std(길이·편차)
* pause_time_ratio(전체 중 침묵 비중), long_pause_rate(0.5초 이상 긴 휴지)

**분절 3개**

* voiced_seg_rate(초당 발화 조각 수), voiced_run_mean/std(조각 길이·편차)

**ZCR 2개** — 평균, 표편

**발화량 2개** — phonation_time, total_speech_dur

→ 26 + 12 + 6 + 3 + 2 + 2 = **51**

**개수가 갈리는 규칙**

* 프레임마다 계산되는 것(MFCC·음질·ZCR) → 평균·표편 2개씩 뽑아서 개수 늘어남
* 전체에서 한 번 세는 것(휴지·분절·발화량) → 이미 요약된 값이라 통계 또 안 뽑음

## 왜 시계열 모델(RNN/Transformer) 안 썼나

* 표본 n=77 → 시계열 딥러닝 쓰면 외워버림(과적합)
* 최종 산출물이 보호자 리포트 → "shimmer가 높습니다"처럼 근거를 말할 수 있어야 함
* 딥러닝 임베딩은 근거 설명 불가
* → 해석 가능성을 성능보다 우선

**시간 구조를 다 버린 건 아님**

* pause·tempo 9개는 평균이 아니라 시간축에서만 나오는 정보
* 언제 얼마나 멈추는가 / 발성이 얼마나 잘게 끊기는가
* 실제로 상위 신호 (pause 0.783, tempo 0.744)

**한계 (정직하게 남길 것)**

* 녹음 앞부분 vs 뒷부분 변화(피로 효과 등)는 평균으로 뭉개져서 안 보임

## 넣었다가 뺀 것

**포먼트 F1~F3 (6개) → 제거**

* 성도 형태 = 조음 정확도 관련이라 넣었음
* Kang에서 판별력 없음. f1_mean 0.503(무작위), 최고가 f3_std 0.651
* 음질 그룹에 넣어도 0.727 → 0.724로 제자리
* **빼니까 음향 전체 0.854 → 0.871로 오름**

**spectral 4종(centroid/bandwidth/rolloff/rms) → 제거**

* 그룹 AUC 0.543. rms는 0.51로 완전히 죽음
* MFCC와 중복 → ZCR(0.709)만 남김

→ 판단 기준: **피처를 늘리는 게 아니라, 줄여서 오르면 줄인다**
→ n=77에서는 약한 피처가 신호가 아니라 잡음

## 계산 비용도 설계 변수

CPP가 병목이었음

* 켑스트로그램 2ms 간격 × 900초 → 파일당 10분
* 77명이면 실험 1회에 12분 → 반복 실험 불가
* → CPP 입력을 중간 60초로 제한 + 간격 10ms로
* 평균 CPP는 60초로도 안정적 → 신호 유지(voice 그룹 0.728), 속도만 확보

## 검증 어떻게 했나

**subject-level 5-fold CV**

* Kang은 파일 1개 = 화자 1명 → 행 단위 분할이 곧 화자 단위 분할
* 같은 사람이 학습·시험에 겹치면 목소리 외워서 맞히는 반칙(leakage)

**지표**

* ROC-AUC(OOF), Recall@90%Spec
* 피처별 단변량 AUC → 어떤 게 신호인지
* 그룹별 ablation → 빼고/그것만으로 재보기

**길이 편향 검사 (계속 걸림)**

* 최강 피처가 "총 발화 시간"(0.866). HC 708초 vs MCI 449초
* 근데 이건 인지력이 아니라 그날 인터뷰가 짧았을 수도
* → 빼고 다시 재봄 → **음향만으로 0.813 유지** = 편향 아닌 실제 신호
* 보고할 땐 (a) 전체 0.871, (b) 발화량 제거 0.813 두 값 같이 씀

**같은 함정 재발 (한국어 마커)**

* 발화당 정규화 → 간투사 AUC 0.785로 최강 신호처럼 보임
* 형태소당으로 바꾸니 **0.578로 붕괴**
* 원인: HC 발화 27.5형태소 vs MCI 15.8형태소로 2배 → 길게 말하면 뭐든 많이 나옴
* → 모든 언어 피처를 형태소당으로 통일

## 결과

* 음향 단독 **AUC 0.871**
* 음향 − 발화량 제거 **0.813** (편향 방어 근거)
* 전체(음향+언어) **0.928**, Recall@90%Spec **0.600** (보조 KPI 달성)
* KPI(MCI AUC ≥0.74) → 음향 단독으로도 PASS

**신호 지형 (단변량 AUC)**

* 발화량 계열 0.87~0.82 ← 편향 주의
* pause 3종 0.79~0.80
* HNR 0.774 / shimmer 3종 0.76대
* tempo(voiced) 0.753
* CPP 0.737 / jitter 0.70~0.73 / f0_mean 0.716
* → 주력: pause · 음질 · tempo. 전부 발화량 무관

**방향 (전부 임상적으로 말 됨)**

* MCI가 shimmer·jitter ↑ (발성 불안정)
* HNR·CPP ↓ (덜 맑고 덜 또렷)
* f0 ↓ (평균 음높이 낮음)
* 휴지 ↓, 발성 조각 길이 ↑ (짧게 끊어 답하고 덜 쉼, 길게 이어 말함)
  → **직관과 반대. 그래서 루브릭 방향을 데이터가 정하게 함**
