# AI-Rookie 미팅 노트 (음향 피처 외)

## 한국어 비유창성

버벅임 축이 5축 중 최약 (0.684) → 간투사·단어반복·휴지 셋뿐이라 표면만 긁음

**믿:음(LLM)에 마커 탐지 시켜봄 → 실패**

* 짧은 예문은 정확한데 실제 대화체 전사에선 못 찾음
* HC 발화에서 없는 마커를 만들어내기까지 함
* 청크 줄이고 프롬프트 조여도 안 됨 → AUC 0.50~0.55, 잡음

**규칙 기반으로 전환 → 성공**

* 관찰된 패턴이 규칙적이라 정규식으로 직접 잡음. API 없이 완전 재현
* 어미 미완성 0.736 / 파편 반복 0.726 / 지시어 남용 0.692
* 버벅임 축 0.690 → 0.879

→ 믿:음이 짧은 예문에서 보여준 마커 정의가 규칙의 뼈대가 됨
→ LLM으로 탐색하고 규칙으로 구현한 셈

## 스코어링 — 발화 5축

버벅임 / 침묵 시간 / 발화 속도 / 발음 정확도 / 문장 완성도

**방향은 데이터가 정하게 함**

* 직관은 "휴지 많으면 나쁨"인데 Kang은 HC가 더 자주 쉼 (0.093 vs 0.035)
* MCI는 짧게 끊어 답하고 덜 쉬는 패턴
* → 직관대로 짰으면 점수가 라벨과 거꾸로 감

**발화량 계열은 점수에서 뺌**

* 최강 피처가 "총 발화 시간"인데 인지력이 아니라 인터뷰 길이 차이일 수 있음
* 빼고 재보니 음향만으로 0.813 유지 → 실제 신호 확인

**점수 = 100 × Φ(z + 1)**

* z = (측정값 − HC평균) / HC표편 × 방향
* 정상군 평균 대비 몇 표준편차인지를 0~100으로 환산
* +1 이동 이유: 신경심리에서 경계로 보는 −1SD가 50점이 되도록 맞춤
* → HC 평균 84점, HC −1SD 50점

## 등급 컷

**85 / 50 채택** → 정상 16명(MCI 6%) / 관찰 필요 43명(49%) / 주의 관찰 18명(100%)

* 선별도구는 MCI 놓치는 게 더 큰 비용 → 정상 등급 MCI가 22%(70/45 컷)에서 6%로 줄어듦
* 대가: 건강한 분 37명 중 22명이 중간 등급에 들어옴
* → 중간 등급 이름을 "위험"에서 "관찰 필요"로 바꿈
* 건강한 분 다수가 받는 등급에 위협적 이름 쓰면 불안만 키우고 도구 신뢰 무너짐

## 스코어링 — 내용 5축

단어 수준 / 문맥 일치도 / 기억 정확도 / 시간·장소 지남력 / 논리 연결

**검증 가능성이 둘로 갈림**

[A] 전사 기반 → Kang으로 검증됨

* 단어 수준 0.723 / 시간·장소 지남력 0.740 / 논리 연결 0.642
* 총점 0.782

[B] 회상 기반 → 검증 불가

* 기억 정확도 / 문맥 일치도
* 이벤트그래프가 정답이라 정오 판정은 확실
* 근데 MCI 환자가 우리 콘텐츠 보고 회상한 데이터가 없음 → 판별력 미측정
* → validated 플래그 달아둠. 총점만 보고 검증된 성능으로 오해하면 안 됨

**시간·장소 지남력을 전사 기반으로 만든 이유**

* 이벤트그래프의 location이 12장면 전부 "알 수 없음" (뉴스라 장소 정보 없음)
* → 전사에서 구체 표현(병원, 서울) vs 지시 표현(여기, 거기)으로 나눠 잼
* MCI가 장소명 대신 지시어에 의존 (0.682)

## 모델 6종

* **A.X K1** — 시청 중 질문 생성
* **A.X STT** — 음성→텍스트. Batch가 화자 분리 지원
* **EXAONE** — 질문 타이밍 판정 + 교차검증
* **Solar** — 요약 / 장면 매칭 / 보호자 리포트
* **믿:음** — 탐지 근거 설명
* **VARCO** — 데모 음성 합성 (노년 화자 65명)

**점수는 규칙, 해석은 LLM**

* LLM에 채점 안 맡김 → 재현 안 되고, "왜 63점인가"에 답 못 하고, AUC로 검증도 못 함
* LLM은 나온 점수를 사람 말로 옮기는 역할만

**생성과 검증 모델 분리**

* Solar가 쓴 리포트를 Solar가 검증하면 같은 편향 공유 → 검증은 EXAONE

## 타이밍 게이트

hard block(규칙) → draft(A.X K1) → judge(EXAONE) → refine

* 시청 방해가 목적이 아니라 제때 묻는 게 목적
* hard block을 앞에 둔 이유: A.X가 팀당 RPS 3 (팀원과 공유) → 규칙으로 먼저 걸러야 함
* 차단 조건: 간격 90초 미만 / 장면 경계 ±3초 / 세션당 5회 / 사용자 발화 중
* 실측: 뉴스 1266초에서 84개 시점 중 5회만 질문

## 검증

* subject-level 5-fold CV — 같은 사람이 학습·시험에 겹치면 목소리 외워서 맞히는 반칙
* 지표: AUC(OOF), Recall@90%Spec, 피처별 단변량, 그룹별 ablation
* LLM 출력 검증 4종: 스키마 / 근거성(출력 숫자가 입력에 있는지) / 진단 단정 금지어 / 재현성
   * 실패 시 뭐가 틀렸는지 피드백해 재생성
   * 1차 3회 중 1회 환각 → 온도 0 + 숫자 규칙 강화 후 3/3 통과
* 등급 단조성: 정상 22% → 관찰 필요 79% → 주의 관찰 100%
