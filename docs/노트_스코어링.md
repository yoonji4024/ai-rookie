# 스코어링

## 발화 5축

버벅임 / 침묵 시간 / 발화 속도 / 발음 정확도 / 문장 완성도

방향은 데이터가 정하게 함

* 직관은 "휴지 많으면 나쁨"인데 Kang은 HC가 더 자주 쉼 (0.093 vs 0.035)
* MCI는 짧게 끊어 답하고 덜 쉬는 패턴
* → 직관대로 짰으면 점수가 라벨과 거꾸로 감
* 각 피처 부호를 학습 fold의 HC/MCI 평균차로 결정. fold 안에서만 fit → leakage 차단

발화량 계열은 점수에서 뺌

* 최강 피처가 "총 발화 시간"(0.866). HC 708초 vs MCI 449초
* 인지력이 아니라 인터뷰 길이 차이일 수 있음
* 빼고 재보니 음향만으로 0.813 유지
* 보고할 땐 전체 0.871 / 발화량 제거 0.813 두 값 같이 씀

축별 판별력

* 버벅임 0.858 / 발화 속도 0.814 / 문장 완성도 0.791 / 발음 정확도 0.785 / 침묵 시간 0.693
* 총점 0.898

## 점수 환산식

점수 = 100 × Φ(z + 1)

* z = (측정값 − HC평균) / HC표편 × 방향
* 정상군 평균 대비 몇 표준편차인지를 0~100으로 환산
* Φ = 표준정규 누적분포
* +1 이동 이유: 신경심리에서 경계로 보는 −1SD가 50점이 되도록 맞춤
* → HC 평균 84점, HC −1SD 50점

z → 점수 대응

* z +1.00 → 97.7점
* z 0 → 84.1점 (HC 평균)
* z −1.00 → 50.0점 (HC −1SD)
* z −2.00 → 15.9점

## 등급 컷

단조성(등급 나빠질수록 MCI 비율 증가) + 최소 인원 만족하는 컷 탐색

* 70/45 → 정상 41명(MCI 22%) / 24명(79%) / 12명(100%)
* 85/50 채택 → 정상 16명(MCI 6%) / 43명(49%) / 18명(100%)

85/50 택한 이유

* 선별도구는 MCI 놓치는 게 더 큰 비용
* 정상 등급 MCI가 22% → 6%로 줄어듦

대가

* 건강한 분 37명 중 22명(59%)이 중간 등급에 들어옴
* → 중간 등급 이름을 "위험"에서 "관찰 필요"로 바꿈

## 내용 5축

단어 수준 / 문맥 일치도 / 기억 정확도 / 시간·장소 지남력 / 논리 연결

검증 가능성이 둘로 갈림

[A] 전사 기반 → Kang으로 검증됨

* 시간·장소 지남력 0.740 / 단어 수준 0.723 / 논리 연결 0.642
* 총점 0.782
* HC 규준 z 점수 (발화 축과 동일 방식)

[B] 회상 기반 → 검증 불가

* 기억 정확도 / 문맥 일치도
* 이벤트그래프가 정답이라 정오 판정은 확실
* MCI 환자가 우리 콘텐츠 보고 회상한 데이터가 없음 → 판별력 미측정
* 규준이 아니라 정답 대비 직접 환산
   * 기억 정확도 = coverage + Kendall's tau 반반
   * 문맥 일치도 = intrusion(없던 내용 말함) 감점
* → validated 플래그 달아둠

시간·장소 지남력을 전사 기반으로 만든 이유

* 이벤트그래프의 classification.location이 12장면 전부 "알 수 없음" (뉴스라 장소 정보 없음)
* → 전사에서 구체 표현 vs 지시 표현으로 나눠 잼
   * 구체: 병원, 서울, 3월 / 지시: 여기, 거기, 어제
   * MCI가 장소명 대신 지시어에 의존 (0.682)
   * 시간 구체성 HC 0.337 vs MCI 0.253
