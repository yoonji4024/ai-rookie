# 교차언어 검증 (영어·중국어)

## 왜 했나

한국어 데이터(DementiaBank Korean)는 HC 37 / MCI 40으로 표본이 작고 AD 라벨이 없음

* n=77이라 fold 표준편차 ±0.12 → 분할에 민감
* AD 판별 KPI(AUC ≥0.80)를 측정할 데이터가 없음
* 우리 음향 지표가 한국어에만 통하는 건지, 언어와 무관하게 치매를 반영하는 건지 알 수 없음

→ 영어·중국어 DementiaBank에 같은 음향 51피처를 그대로 적용

## 데이터 확보

오디오와 라벨의 출처가 달랐음

* 오디오: media.talkbank.org에서 wget
   * 그냥 mp3 URL을 받으면 11바이트 껍데기(플레이어 페이지 HTML)
   * `?f=save` 붙여야 실제 파일
* 라벨: 코퍼스별 전사 zip의 각 .cha 파일 `@ID` 줄 6번째 필드
   * `@ID: eng|Pitt|PAR|70;|female|Control||Participant|30||`
   * 폴더 구조(Control/Dementia)에 의존하지 않음 — 폴더에 라벨 없는 코퍼스가 다수

`dementiabank_labels.py`로 전사 zip → CSV 1,760명 (정상 552 / MCI 317 / 치매 891)

### 쓴 코퍼스

| 코퍼스 | 언어 | 구성 | 용도 |
|---|---|---|---|
| Pitt | 영어 | 정상 243 / 치매 260 | AD 판별 주력 |
| Delaware | 영어 | 정상 279 / MCI 159 | MCI 전용 (치매 라벨 없음) |
| Lu | 중국어 | 정상 26 / 치매 24 | 제3 언어 |

### 제외한 코퍼스

라벨이 비어 있어 못 씀

* WLS 1,364명 — `@ID` 진단 필드 전부 빈칸. 위스콘신 일반 노인 종단코호트라 치매 케이스 모음이 아님
* VAS 100 · Kempler 7 · Holland · Lanzi — 진단 필드 빈칸
* Hopkins · DePaul · Baycrest-PPA — PPA(원발성진행성실어증)만 있고 정상 대조군 없음

## 결과

화자 단위 5-fold, 음향 51피처만 (언어 피처 0개, 전사 없음)

| 대상 | AUC |
|---|---|
| Pitt 정상 vs 치매 (영어) | 0.765 |
| Lu 정상 vs 치매 (중국어) | 0.811 |
| Delaware 정상 vs MCI (영어) | 0.598 |
| 한국어 정상 vs MCI (음향+언어) | 0.928 |

한국어·영어·중국어 세 언어에서 음향 지표가 판별력을 보임

* 전사 없음, 언어 피처 없음, 언어가 다름 → 그래도 작동
* 음향을 원본 파형에서 직접 뽑는 설계가 언어에 의존하지 않음을 뒷받침

## 통합 수치를 대외에 쓰지 않는 이유

전 코퍼스를 합치면 AUC 0.883이 나옴. 이 값은 쓰지 않음

* Delaware(279명)가 정상만 제공하고, 치매는 Pitt·Lu에서 옴
* 분류기가 "치매 신호"가 아니라 "어느 코퍼스 녹음이냐"를 일부 학습할 수 있음
   * 녹음 환경·마이크·과제가 코퍼스마다 다름
* 따라서 0.883은 낙관적 상한으로만 취급, 대외 수치는 코퍼스 내 값(0.765 / 0.811) 사용

발화량 편향 때와 같은 종류의 문제 — 성능이 우리가 재려던 것에서 나왔는지 확인해야 함

## MCI는 음향만으로 약함

Delaware 정상 vs MCI 0.598

* 음향 단독으로는 MCI 신호가 미세해서 안 잡힘
* 문헌과 일치 (ADReSS 음향 단독 62.5%)
* 한국어에서 0.928이 나온 건 음향+언어 결합이었음
* → 조기 신호 탐지에는 언어 피처와 회상 과제가 필요. 음향만으로 MCI KPI(0.74) 도달 못 함

## 휴지 방향이 언어에 따라 뒤집힘

| 지표 | 한국어 | 영어·중국어 |
|---|---|---|
| 휴지 비율 | 정상이 더 자주 쉼 | 치매가 더 오래 쉼 (0.411 vs 0.519) |

단변량 AUC 0.687로 통합 기준 최고 판별력. 방향은 반대

* 한국어는 인터뷰, 영어·중국어는 그림설명 과제 → 과제 특성 차이로 보임
* "휴지가 많으면 나쁘다"를 규칙으로 박아뒀다면 언어가 바뀌는 순간 틀렸음

→ 각 피처의 부호를 학습 fold의 HC/MCI 평균차로 결정하는 설계의 실증 근거

같은 통합 기준 다른 지표: voiced_seg_rate 0.656, HNR 0.586, f0_mean 0.563

## 트러블슈팅

praat 음질 계산이 파일당 병목

* HNR(`To Harmonicity`)이 긴 파일에서 수십 초 소요, 552개면 수십 분
* 중단되면 계산분 전부 소실 → 피처를 계산 즉시 CSV에 append하는 캐시 추가
* 예외 발생 파일은 스킵하고 계속 진행 (깨진 파일 하나가 전체를 막지 않게)
* SSH 끊김 대비 `nohup`으로 실행

쿠키 만료로 다운로드 중단

* 세션 쿠키가 중간에 만료되어 11바이트 껍데기 파일이 쌓임
* `find -size -1k -delete`로 껍데기 제거 후 재로그인, `-nc`로 이어받기

## 남은 것

* 파일럿 세션 확보 후 런타임 참조분포 보정 — 학습 데이터는 인터뷰/검사 발화, 실사용은 편한 대화
* 언어 피처를 붙인 영어 MCI 판별 (현재 음향만이라 0.598)
