# STT 도메인 시프트

## 왜 쟀나

현재 성능(AUC 0.928)은 사람이 만든 gold 전사 기준
실제 서비스는 A.X STT 출력으로 돌아감
→ STT가 disfluency를 다듬으면 신호가 사라짐. 실전 성능의 상한을 이 실험이 결정

## 방법

Kang 40명 (HC 20 / MCI 20), A.X STT Batch

참가자 구간만 잘라서 전사 (`--mode par`)

* Kang은 조사자(INV)+참가자(PAR) 인터뷰
* STT 화자 분리는 턴 경계에서 샘 ("드라마 제목이 어떻게 돼요?"의 뒷부분이 참가자로 오분류)
* .cha에 PAR 발화 시각이 있으므로 그 구간만 잘라 넣으면 화자 분리 불필요
* 조사자 30% 제거됨 (982초 → 689초)
* 런타임에는 어르신 혼자 말하므로 이 문제 없음. Kang 인터뷰 특성

## 결과

WER 0.352 (문장부호 정규화 후, 중앙값 0.312)

* 정규화 전 0.429는 Kang CHAT 형식(부호가 띄어쓰기로 분리)이라 부풀려진 값
* 인식이 완벽해도 "봤어요 ." vs "봤어요." 때문에 오류로 잡힘

보존됨

* 지시어 109% (0.593 → 0.560)
* 인접 반복 109% (0.540 → 0.568)
* 간투사 102% (0.562 → 0.620)
* 단어 찾기 89% (0.511 → 0.601)

소실

* 어미 미완성 43.6% (0.760 → 0.527)
* 파편 반복 14.4%
* 총합 87% (0.638 → 0.518)

## 함의

* 현재 0.928은 gold 전사 기준. STT 런타임에선 그대로 재현 안 됨
* 보고 시 gold 기준 / STT 기준 분리 표기
* CLAUDE.md 13장 열린항목 "A.X STT가 disfluency 보존하는가" 해소 → 보존 안 함

대응

* 소실된 두 신호를 음향 피처로 대체
   * 어미 미완성 → 발화 말단 F0 하강 / 에너지 감쇠 / 후행 침묵
   * 파편 반복 → 짧은 발성 조각의 빈발 (voiced_seg 통계)
* 음향은 STT를 안 거치므로 정규화 영향 없음

## 소표본 함정 (기록)

* 1차 `--limit 10`은 앞에서 자르는 방식이라 전원 HC → AUC 전부 nan
* → 균등 추출로 수정
* 파편 반복은 희소 신호 (일부 MCI에만 출현) — 10명 표본에선 gold조차 0이었음
