# 도메인 시프트와 VAD

## 증상

임상 데이터 3명(CDR 0 / 0.5 / 1)을 채점했더니 **모두 85~100점**으로 나와 구분이 안 됐다.
치매 환자가 정상과 같은 점수. 실제 녹음도 전 축이 88~100에 몰렸다.

## 원인

병이 아니라 **입력을 다르게 만들어 넣고 있었다.**

| | 휴지 비율 |
|---|---|
| Kang HC (참조분포) | 0.080(여) ~ 0.149(남) |
| 임상 데이터 | 0.326 |
| 실제 녹음 | 0.567 |

참조분포는 CHAT 전사의 발화 타임스탬프로 **참가자 발화 구간만** 잘라 계산했다.
조사자 발화와 긴 무음은 애초에 빠져 있다.
런타임은 **전체 오디오를 통째로** 넣었다 → 무음이 전부 '휴지'로 계산됨.

z가 +3~+4로 포화되고, 100점 상한에 걸려 누구를 넣어도 같은 점수가 나왔다.

## 조치 — VAD로 발화 구간만 추출

`extract_acoustic.vad_segments()`

- 음성 구간 검출 (top_db=30)
- 간격 1.0초 미만이면 한 발화 내부 휴지로 보아 병합
- 0.3초 미만 조각 제거

→ 발화 **내부** 휴지는 보존(측정 대상), 발화 **사이** 공백은 제외.
   Kang의 발화(utterance) 단위를 흉내낸 것.

`segments`가 주어지면(학습) 그대로 쓰고, 없으면(런타임) VAD로 추정한다.
`use_vad=False`로 끄면 A/B 비교 가능.

## 결과

### 지표가 참조 범위로 복귀 (실제 녹음)

| 지표 | 전체 | VAD | Kang HC 범위 |
|---|---|---|---|
| 휴지 비율 | 0.567 | **0.118** | 0.080~0.149 |
| 휴지 빈도 | 2.389 | **0.339** | 0.208~0.342 |
| 유성구간율 | 3.237 | **0.566** | 0.438~0.595 |

평균 z **+3.02 → +0.38**. 극단값에서 정상군 평균 근처로.

### 점수 포화 해소

| 축 | VAD 없음 | VAD 적용 |
|---|---|---|
| 버벅임 | 100 | 99 |
| 침묵 시간 | 99 | **73** |
| 발화 속도 | 91 | **62** |
| 발음 정확도 | 47 | **95** |
| 문장 완성도 | 88 | 92 |

88~100에 몰려 있던 점수가 62~100으로 퍼졌다. 축이 변별력을 갖게 됨.

**발음 정확도 47 → 95**가 특히 중요하다. 처음엔 마이크 품질 문제로 추정했으나 아니었다.
**무음 구간이 음질(HNR·CPP) 계산에 섞여** 낮게 나온 것이었다. 발화 구간만 쓰니 정상값.

## 임상 데이터로 CDR 구분 시도 — 실패 (데이터 한계)

화자 분리(A.X STT)까지 적용해 CDR 0 / 0.5 / 1을 구분할 수 있는지 확인했다.

| 대상 | 전체 | VAD | 화자분리 |
|---|---|---|---|
| 정상 CDR0 | 89 | 85 | 81 |
| MCI CDR0.5 | 92 | 89 | 87 |
| 치매 CDR1 | 91 | 87 | 83 |

**세 방식 모두 CDR 순서와 무관.** 점수 폭도 3~6점에 불과.

### 왜 안 되는가 — 지표가 아니라 표본의 문제

- **주화자 비중 52% / 52% / 74%.** Kang 인터뷰에서는 참가자가 98.8%였으나,
  임상은 전화 통화라 조사자와 참가자가 반반씩 말했다.
  → "가장 오래 말한 화자"가 참가자인지 조사자인지조차 불확실. 2명은 조사자를 채점했을 수 있다.
- **n=3, 치매 1명.** 애초에 통계적 판단이 불가능한 규모.
- 녹음 환경(전화)이 참조분포(인터뷰)와 여전히 다르다.

### 결론

임상 3명은 **검증용으로 쓸 수 없다.** 동작 확인용으로만 취급한다.
판별력 검증은 규모 있는 데이터로 이미 확보되어 있다 —
DementiaBank Korean 0.928(n=77) · Pitt 0.765(n=503) · Lu 0.811(n=50).

## 남은 문제 — 임상 데이터는 절반만 해결

| | 전체 | VAD |
|---|---|---|
| 정상 CDR0 | 0.326 | 0.187 |
| MCI CDR0.5 | 0.290 | 0.205 |
| 치매 CDR1 | 0.346 | 0.163 |

Kang 범위(0.080~0.149)에 못 미친다. **전화 통화라 조사자 음성이 섞여 있고,
VAD는 "사람이 말한다"만 알 뿐 "누가 말하는지"는 모르기 때문.**

→ 화자 분리 필요. A.X STT batch가 화자 인덱스를 제공하며,
   Kang HC_01에서 참가자 98.8% / 조사자 1.2%로 정확히 분리됨을 확인했다.
   `src/api/clinical_diarize.py` — **서버에서 실행**(맥은 STT 업로드가 WAF에 막힘).

**단, 실제 런타임은 사용자 혼자 말하므로 이 문제가 없다.** 화자 분리는 임상 데이터를
검증에 쓰기 위해 필요한 것이지, 서비스 동작에는 불필요.

## 참조분포의 한계 (별건, 미해결)

Kang HC 성별 구성이 **남 7명 / 여 30명**으로 치우쳐 있다. 사실상 여성 기준 참조분포.

성별 분리도 검토했으나 채택하지 않았다.
- 남성 7명으로 만든 참조분포가 더 불안정
- 분리 시 표준편차 감소폭이 0% 내외 또는 음수 → 실익 없음

휴지 계열의 성별 차이(0.08 vs 0.15)보다 조건 차이(0.33~0.57)가 3~7배 커서,
성별은 부차적 요인이었다. **제안서에 한계로 명시할 것.**
