# 음향 피처

## 왜 STT를 안 거치나

A.X STT가 음성을 텍스트로 → 발화를 매끄럽게 다듬는 문제 발생

* 음성에 있는 더듬거림이 MCI의 증거인데 다듬으면 곤란
   * "제가 즈 , 나 , 제 , 제가" → "제가"
* 어미 미완성 보존율 43.6%, 파편 반복 14.4%만 남음
* 판별력 gold 0.760 → STT 0.527

→ 음향 피처는 STT를 거치지 않고 원본 파형에서 직접 추출

## 최종 Feature

원본 16kHz 시계열 → 900초면 1440만 개 샘플이라 그대로 못 씀

1단계. 프레임으로 쪼갬

* 25ms씩 자르고 10ms씩 밀면서 각 순간의 음높이, 떨림, 스펙트럼 계산
   * 25ms인 이유: 성대 1회 진동이 5~10ms
      * 25ms면 2~3회 들어가서 이 구간 음높이 170Hz라고 말할 수 있음
      * 더 길면 그 안에서 음높이가 변해버려서 하나로 못 말함
   * 10ms씩 미는 이유: 25ms 재고 25ms 옮기면 경계에서 정보 끊김
      * 10ms면 15ms씩 겹쳐서 변화를 부드럽게 따라감
* 900초 / 10ms = 화자당 9만 프레임

2단계. 통계로 요약

* 지표마다 9만 개 숫자가 쌓임 → 그대로 못 씀
* 평균/표준편차로 줄임
   * 음높이 9만 개 → 평균 170.9Hz, 표편 47.0Hz 두 개

3단계. 화자당 고정 길이 벡터 = 51차원

## 51차원 구성

MFCC 26차원

* MFCC = 스펙트럼을 13차원으로 압축한 음색 지문
* 13차원 각각에 9만 프레임의 평균/표편 → 13 * 2 = 26

음질 12차원

* 음높이 4개: f0_mean, f0_std, f0_range, f0_cv
* jitter 3종: local, rap, ppq5 → 짧은 주기 / 중간 주기 떨림을 따로 봄
* shimmer 3종: local, apq3, apq5
* HNR 1개(배음 대비 잡음 = 맑기)
* CPP 1개(주기성·명료도)
* 3종씩 넣은 이유 → 어느 게 신호인지 미리 모름. 표준 패널 다 넣고 데이터로 고름

pause 6차원

* pause_ratio(쉬는 비율)
* pause_rate(빈도)
* pause_dur_mean/std(길이/편차)
* pause_time_ratio(전체 중 침묵 비중)
* long_pause_rate(0.5초 이상 긴 휴지)

분절 3차원

* voiced_seg_rate(초당 발화 조각 수)
* voiced_run_mean/std(조각 길이/편차)

ZCR 2차원 — 평균, 표편

발화량 2차원 — phonation_time, total_speech_dur

개수가 갈리는 규칙

* 프레임마다 계산되는 것(MFCC·음질·ZCR) → 평균/표편 2개씩 뽑아서 개수 늘어남
* 전체에서 한 번 세는 것(pause·분절·발화량) → 이미 요약된 값이라 통계 또 안 뽑음

## 넣었다가 뺀 것

포먼트 F1~F3 (6개) → 제거

* Kang에서 판별력 없음 (f1_mean 0.503, 최고가 f3_std 0.651)
* 음질 그룹에 넣어도 0.727 → 0.724
* 빼니까 음향 전체 0.854 → 0.871

spectral 4종(centroid/bandwidth/rolloff/rms) → 제거

* 그룹 AUC 0.543, rms 0.51. MFCC와 중복
* ZCR(0.709)만 남김

## 계산 비용

CPP가 병목

* 켑스트로그램 2ms 간격 × 900초 → 파일당 10분, 77명이면 1회 실험에 12분
* → CPP 입력을 중간 60초로 제한 + 간격 10ms
* 신호 유지(voice 그룹 0.728), 속도 확보

## 시계열 모델을 안 쓴 이유

* n=77 → RNN/Transformer는 과적합
* 최종 산출물이 보호자 리포트 → 근거를 말할 수 있어야 하는데 딥러닝 임베딩은 불가

시간 구조를 다 버린 건 아님

* pause·분절 9개는 시간축에서만 나오는 정보
* 실제로 상위 신호 (pause 0.783, 분절 0.744)

한계

* 녹음 앞부분 vs 뒷부분 변화(피로 효과 등)는 평균으로 뭉개져서 안 보임

## 결과

* 음향 단독 AUC 0.871
* 음향 − 발화량 제거 0.813
* 신호 지형: 발화량 0.87~0.82 / pause 0.79~0.80 / HNR 0.774 / shimmer 0.76대 / 분절 0.753 / CPP 0.737 / jitter 0.70~0.73 / f0_mean 0.716

방향

* MCI가 shimmer·jitter ↑, HNR·CPP ↓, f0 ↓
* 휴지 ↓, 발성 조각 길이 ↑ (짧게 끊어 답하고 덜 쉼)
   * 직관과 반대 → 루브릭 방향을 데이터가 정하게 한 이유
