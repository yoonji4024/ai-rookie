# AI 동반 미디어 시청 기반 인지 스크리닝 시스템 — 연구 개요

2026 인공지능 루키 대회 국내 AI 트랙 · 성균관대학교 소프트웨어학과

---

## 1. 문제 정의

경도인지장애(MCI)와 초기 치매는 조기 발견 시 개입 효과가 크지만, 병원 방문 기반 검사(MMSE 등)는 접근성이 낮고 일회성이라 변화 추적이 어렵다. 일상 속에서 부담 없이 반복적으로 인지 상태의 신호를 수집할 방법이 필요하다.

특히 고령자는 화면 조작·타이핑이 어렵고 "검사받는다"는 인식 자체가 부담이 된다. 조작 없이, 평소 행동 안에서 자연스럽게 데이터를 얻는 설계가 요구된다.

---

## 2. 핵심 아이디어

어르신이 평소처럼 드라마·뉴스를 시청하는 상황을 스크리닝 환경으로 활용한다. 새로운 기기 조작을 배울 필요 없이, 원래 하던 TV 시청과 말하기만으로 데이터가 수집된다.

- **시청 중**: AI가 친구처럼 자연스럽게 실시간 질문을 던지며 대화한다. 타이밍 게이트가 질문 시점을 제어해 시청을 방해하지 않는다.
- **시청 후**: 방금 본 콘텐츠의 장면 순서를 회상하는 질문을 제시한다. 자막과 타임스탬프로 구성된 이벤트 그래프가 정답 역할을 하므로, 자유 회상과 달리 응답의 정오와 오류 유형을 객관적으로 판정할 수 있다.
- **리포트**: AI는 진단명을 내리지 않는다. 순서 오류, 발화 신호 등 객관적 근거만 보호자 리포트로 전달하며, 보호자는 해당 답변을 직접 확인할 수 있다.

입력은 전 과정에서 **음성**이다. 조작은 보호자가 맡고 어르신은 시청·대화만 한다.

---

## 3. 시스템 구성

3-에이전트 파이프라인과 국내 기업 AI 모델 6종으로 구성된다.

**대화 에이전트 (시청 중)**
타이밍 게이트가 draft(SKT A.X K1) → judge(LG EXAONE) → refine 3단계로 질문 여부와 시점을 결정한다. 규칙 기반 차단 레이어가 API 호출 전 시청 방해 조건(질문 간격, 장면 몰입 구간, 발화 중 여부)을 먼저 거른다.

**요약·분석 에이전트 (시청 후)**
회상 발화를 이벤트 그래프의 장면에 매칭(Upstage Solar)하고, 순서 정확도(Kendall's tau)와 오류 유형(누락·역전·삽입)을 산출한다. 음향·언어 피처로 인지 신호를 정량화하고 발화·내용 10축 점수를 매긴다.

**리포트 에이전트**
규칙으로 산출한 점수를 KT 믿:음이 한국어 근거로 설명하고, Solar가 보호자용 리포트를 생성한다. LG EXAONE이 리포트를 독립 검증한다.

**모델 역할 분담**
음성 인식(A.X STT), 실시간 질문(A.X K1), 타이밍 판정·교차검증(EXAONE), 요약·매칭·리포트(Solar), 탐지 근거 설명(믿:음), 음성 합성(NC VARCO).

---

## 4. 분석 방법

**음향 분석 (STT 비의존)**
원본 오디오를 25ms 프레임으로 분석해 음질(F0·jitter·shimmer·HNR·CPP), 휴지, 발화 분절, 음색(MFCC) 등을 추출한다. STT가 더듬거림·미완성 발화를 정규화해 인지 신호를 지우는 문제를 피하기 위해, 음향 피처는 텍스트를 거치지 않고 원본 파형에서 직접 산출한다.

**언어 분석**
전사 텍스트에서 어휘 다양성, 통사 복잡도, 한국어 비유창성(어미 미완성·단음절 파편 반복·지시어 남용), 시간·장소 표현의 구체성을 정량화한다.

**순서 회상 분석**
이벤트 그래프를 정답으로 삼아 회상 순서를 채점한다. 자유 회상과 달리 객관적 정답이 있어 정오·오류 유형 판정이 가능하다.

**스코어링**
발화 5축(버벅임·침묵·발화속도·발음정확도·문장완성도), 내용 5축(단어수준·문맥일치·기억정확도·시간장소지남력·논리연결)을 0~100점으로 환산한다. 정상군 분포를 규준으로 삼고, 각 지표의 방향은 임상적 직관이 아니라 데이터에서 결정한다. 점수 산출은 규칙 기반으로 하여 재현성과 설명 가능성을 확보하고, LLM은 해석만 담당한다.

## 5. 데이터

- **알고리즘 검증**: DementiaBank Korean 인터뷰 음성 코퍼스(정상·MCI 라벨). 화자 단위 교차검증으로 leakage를 차단해 성능을 평가.
- **이벤트 그래프**: 방송 콘텐츠(뉴스·교양·문화·생활)의 자막·타임스탬프·하이라이트.
- **향후 확보 계획**: 표준 인지검사로 라벨이 확정된 고령자에게 시청 프로토콜을 추가 시행하는 임상 공동연구. 국내 치매 코호트는 라벨은 풍부하나 음성 모달리티가 없어, 음성 데이터는 직접 수집이 필요하다.

---

## 6. 성능

- MCI 판별 AUC 0.928 (화자 단위 5-fold 교차검증)
- Recall@90%Spec 0.600 (보조 목표 달성)
- 음향 단독 0.871
- 발화 5축 총점 0.898 / 내용 3축(검증 가능 축) 총점 0.782
- 대회 KPI(MCI AUC ≥ 0.74) 충족

---

## 7. 신뢰성 검증

- **화자 단위 교차검증**으로 같은 화자의 학습·평가 혼입을 차단.
- **발화량 편향 통제**: 발화량 계열 피처는 인터뷰 길이 차이를 반영할 수 있어 점수 산출에서 제외. 제외 후에도 음향 단독 0.813을 유지함을 확인.
- **LLM 출력 검증**: 스키마·근거성(입력에 없는 수치 생성 금지)·진단 단정 금지·재현성을 자동 검사하고, 생성 모델과 검증 모델을 분리.
- **런타임 조건 측정**: STT를 거친 실전 조건에서 성능이 어떻게 변하는지 정량 측정. 지시어·간투사 등은 보존되나 어미 미완성·파편 반복은 STT 정규화로 소실됨을 확인하여, 해당 신호는 음향 피처로 대체하는 방향을 설정.

---

## 8. 한계와 향후 과제

- **회상 기반 지표의 검증**: 기억 정확도·문맥 일치도는 이벤트 그래프로 정오 판정은 가능하나, 실제 인지 상태와의 상관은 임상 데이터 확보 후 검증이 필요하다.
- **AD 판별**: 현재 데이터에 알츠하이머 라벨이 없어 미측정. 라벨 데이터 확보 후 진행.
- **런타임 신호 보강**: STT에서 소실되는 비유창성 신호를 음향 기반으로 대체하는 피처 개발.
- **추가 검사 축**: 언어 유창성 검사(범주 유창성 등) 등 정답이 명확한 축을 확대해 검증 가능성을 높인다.
- **실환경 데이터**: 표준검사 라벨을 갖춘 고령자 대상 시청 프로토콜 시행으로 실증 데이터 확보.
