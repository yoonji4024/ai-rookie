# 검증

## 분류 성능

subject-level 5-fold Stratified CV

* Kang은 파일 1개 = 화자 1명 → 행 단위 분할이 곧 화자 단위 분할
* 같은 사람이 학습·시험에 겹치면 leakage

지표

* ROC-AUC (OOF)
* Recall@90%Spec
* 피처별 단변량 AUC — 어떤 게 신호인지
* 그룹별 ablation — 빼고 / 그것만으로 재보기

결과

* 전체 AUC 0.928, fold 편차 ±0.080
* Recall@90%Spec 0.600 (보조 KPI ≥0.60 달성)
* 음향 단독 0.871 / 발화량 제거 0.813

## 스코어링 검증

leakage 차단

* 참조분포(HC 평균/표편)와 방향을 학습 fold에서만 fit
* 전체 데이터로 fit하면 MCI 정보가 방향 결정에 새어 낙관적으로 나옴

등급 단조성

* 등급 나빠질수록 MCI 비율 증가하는지 확인
* 정상 22% → 관찰 필요 79% → 주의 관찰 100% (HC 0명)

등급 컷 탐색

* 단조성 + 각 등급 최소 8명 만족하는 조합을 자동 탐색

## LLM 출력 검증 4종

1. 스키마 준수 — 필수 키·축 이름 일치
2. 근거성 — 출력에 등장하는 숫자가 입력에 실제로 있는지 자동 대조
3. 진단 단정 — 금지어 검사 (치매 / 경도인지장애 / 환자 / 진단됩니다)
4. 재현성 — 같은 입력 반복 호출 시 점수 인용·스키마 일관성

실패 시 뭐가 틀렸는지 피드백해 재생성하는 루프 (최대 2회 재시도)

결과

* 1차: 3회 중 1회 없는 수치 인용 (34, 62)
* 온도 0.2 → 0.0, 숫자 인용 규칙 강화 ("입력에 적힌 값만 그대로, 계산·추정 금지")
* 2차: 3/3 통과, 전부 1회 시도

## EXAONE 교차검증

생성(Solar)과 검증(EXAONE) 모델 분리
같은 모델이 자기 출력을 검증하면 편향 공유

검증 항목

* 리포트가 측정값을 왜곡·과장하지 않았는지
* 진단처럼 읽히지 않는지
* 장면 매칭이 타당한지 (근거 약한 매칭 / 놓친 장면)

## 자동 감지 장치

같은 실패 양상이 반복돼서 코드에 감지 로직을 넣음
전부 "놓친 걸 정상으로 판정"하는 방향

* 키워드 중복 → 누락을 정상 회상으로 오판
* LLM 과다 매칭 → 동일
* 검증기가 빈 데이터를 통과 처리 → 데이터 0개인데 "검증 통과"
* 믿:음 호출 실패를 0으로 기록 → '실패'와 '마커 없음' 구분 안 됨

넣은 장치

* 대본이 선언한 omitted_scenes를 매칭기가 잡아내면 과다 매칭 경고
* 이벤트 그래프 0개면 검증 통과가 아니라 중단 + 해결 방법 안내
* LLM 실패 시 error 기록, 전원 0이면 판정 거부
* 소표본(<30)이면 AUC 해석 주의 경고
